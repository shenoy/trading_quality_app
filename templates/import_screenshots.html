What it does

{{ account.name }} has {{ total_trades }} trade{{ '' if total_trades == 1 else 's' }}; {{ missing_now }} {{ 'has' if missing_now == 1 else 'have' }} no screenshot yet.

  • Each row in your sheet is matched to a trade by ticker + date + entry time.
  • Missing screenshots are filled in. A screenshot you already have is never changed.
  • Rows that aren't in the app can be added as new trades. Setup quality is guessed from the notes; the other questions are set to No. You can change them in the preview.
  • Only the account shown above is touched.
  • The sheet needs a ticker, date and entry time. To fill screenshots it needs a screenshot link column; to add new trades it needs risk, R:R and equity. A header row isn't required.
  • Works with .xlsx and .csv files.
